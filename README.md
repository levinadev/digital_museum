# Digital Museum — «Свет и форма»

Виртуальная выставка цифрового искусства: двенадцать работ о том, как геометрия, свет и движение становятся образом.

Все картины нарисованы кодом — это SVG, которые генерируются в браузере. Авторы и работы вымышлены.

## Возможности

- **Галерея из 12 работ** в четырёх категориях: Геометрия, Свет, Природа, Движение.
- **Фильтр по категориям** над сеткой карточек.
- **Окно просмотра** с описанием работы, автором и годом.
- **Листание работ** кнопками ← / →. Окно закрывается кнопкой ×, кликом по фону или клавишей `Esc`. Стрелки на клавиатуре тоже листают.
- **Генеративные картины.** У каждой работы есть стиль (`style`), палитра (`palette`) и зерно (`seed`), поэтому картина при каждой загрузке получается одинаковой.
- **Адаптивная вёрстка** для ПК, планшетов и телефонов.
- **Доступность:** ARIA-атрибуты, видимый фокус, поддержка `prefers-reduced-motion` (для тех, кто просит меньше анимаций).

## Технологии

Чистые HTML, CSS и JavaScript: без фреймворков, сборки и зависимостей. Из внешних ресурсов подключается только шрифт [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) из Google Fonts.

## Запуск

Склонируйте репозиторий и откройте `index.html` в браузере:

```bash
git clone git@github.com:levinadev/digital_museum.git
cd digital_museum
xdg-open index.html   # Linux; на macOS — open index.html
```

Можно запустить и через локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Как добавить работу

1. Добавьте объект в массив `WORKS` в `script.js`:

   ```js
   {
     title: "Название", author: "Автор", year: 2026, category: "Свет",
     style: "glow", seed: 99, palette: ["#0a0a12", "#ff7a59", "#ffc15e", "#c86bfa", "#4cc9f0"],
     description: "Короткое описание работы."
   }
   ```

   - `style` — имя функции из объекта `PAINTERS`, которая рисует картину (`orbits`, `grid`, `bauhaus`, `glow`, `rays`, `aurora`, `mountains`, `sea`, `dunes`, `waves`, `spiral`, `flow`).
   - `seed` — число, от которого зависит «случайность» картины. Если поменять его, получится другой вариант той же картины.
   - `palette` — пять цветов: сначала фон, потом четыре основных цвета.

2. Чтобы добавить новый стиль, напишите функцию в `PAINTERS`. Она получает `(random, palette, id)` и возвращает строку с SVG-элементами.

3. Для новой категории допишите её название в массив `CATEGORIES`.
